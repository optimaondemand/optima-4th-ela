Grammar: Comparative Adjectives
3 points
Identification
1Which sentence uses comparative adjectives correctly?
  • AThe second escape route was more longer and more dangerous.
  • BThe second escape route was longer and more dangerous.
  • CThe second escape route was more long and dangerouser.
Use -er for short adjectives (longer, colder) and more for longer adjectives (more dangerous). Never use both at the same time — "more longer" is a double comparative error.
Fix It
2Fix the comparative adjective errors in this sentence:

"Harriet was more braver than anyone expected, and the nights were more cold than before."
Application
3Write a sentence comparing two parts of Harriet's journey using comparative adjectives (for example: longer, more dangerous, harder, more frightening).
